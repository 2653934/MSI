\section*{AI declaration: how AI was used, and representative prompts}
\small
\textbf{Working system.} I ran the project as a supervised workflow with three
AI roles and a written, append-only supervision log. An AI supervisor (ChatGPT
at first, then Claude) helped me plan experiments, proposed
predeclared decision rules and checked each reported result against the saved
outputs. Claude Code implemented and ran the code and cluster jobs and reported
back in the log. The log was the only channel between the roles: each
implementation task ran in a fresh Claude Code session briefed from the log,
which kept each session focused on one task and limited usage, and the
supervisor read and checked each report before the next step. OpenAI Codex independently reviewed every code change and, once
I approved it, committed it under my account with messages I set rules for. The
goals were fixed by me: a fair, matched-budget comparison; decision rules
written before results; and no claim without a saved result behind it. Every
experiment, cluster job, rule change and commit needed my explicit approval.

\textbf{Writing.} I had the assistant compile every verified result into an
evidence dump organised by report section. I then chose what the report should
contain, set its structure and framing, and had the assistant draft sections
from that selection. I reviewed every draft, rejected or redirected large parts
of it (for example the framing, the research questions, the figures and the
statistical presentation) and approved the final text. The prompts below
are a small selection from several hundred exchanges over the project, chosen
to illustrate how methodological decisions and the writing were directed; they
do not cover every use. They are quoted as written (typos corrected; [\ldots]
marks omitted text), and the full logs are available on request.

\subsection*{Questioning methods and results}
\begin{itemize}
  \item \emph{ChatGPT:} ``We only tested the neighbourhood's contribution to
        reconstruction but how did we know it wouldn't end up being better for
        the peak picking?''
  \item \emph{ChatGPT:} ``Does this mean that there's a chance that our model
        just doesn't perform better than a standard VAE?''
  \item \emph{ChatGPT:} ``How else do we properly test that spatial has an
        impact?''
  \item \emph{ChatGPT:} ``What about S3PL runtime? Are we finally fully grabbing
        that information to have proper and fair comparisons with our model?''
  \item \emph{ChatGPT:} ``didn't we only use 1 seed [\ldots] do we need
        to run the experiments more times to verify?''
  \item \emph{ChatGPT:} ``I do not want to conclude that a neighbourhood
        has no contribution especially since we have a very simple neighbourhood
        that we are using [\ldots] what would [our ablation study] look like?''
  \item \emph{Claude:} ``Why did we not end up using Mann--Whitney as a
        statistical analysis method?''
  \item \emph{Claude:} ``Why didn't we evaluate when the scores are no
        longer increasing and choose that as our epochs?'' (I accepted the
        advice that this would tune on the evaluation labels; training loss is
        reported instead.)
\end{itemize}
