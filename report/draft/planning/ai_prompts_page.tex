\section*{AI declaration: representative prompts}
\small
AI tools were used under a fixed division of roles. An AI supervisor (ChatGPT,
later Claude) helped plan experiments, proposed decision rules and reviewed
results; Claude Code wrote, tested and ran code and cluster jobs; and OpenAI
Codex reviewed and committed changes. Every experiment, cluster job and commit
required my explicit approval, and the full supervision log is kept in the
project repository. The prompts below are representative, quoted as written
(obvious typos corrected; [\ldots] marks omitted text).
