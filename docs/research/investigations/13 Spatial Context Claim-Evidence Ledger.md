# Spatial-context claim–evidence ledger

Status: 6 October 2026. This is the bounded synthesis of the completed seed-1 attention interventions, not the final claim ledger for every method in the report. Source results are the locally synced cluster outputs. No new training or evaluation was run for this note.

## What was held fixed

The [frozen input swap](../../../code/msi/results/diagnostics/spatial_attention_input_swap/) feeds real or nonlocally shuffled neighbours to the same real-neighbour-trained attention checkpoint, retaining each section's real-input GMM. It measures reconstruction, latent and GMM changes; it does **not** calculate a new IG ranking or mSCF1. The [frozen ranking swap](../../../code/msi/results/diagnostics/spatial_attention_frozen_ranking_swap/) then holds the checkpoint, real-input GMM, attribution pixels, target components and section-specific peak count fixed while recomputing IG with shuffled neighbours. Expert masks enter only the post-hoc PCC/F1 evaluation, not the ranking. This is an input intervention on a model trained with real neighbours, not a fair comparison of two separately trained deployment models.

The [changed-peak audit](../../../code/msi/results/diagnostics/spatial_attention_changed_peaks/) identifies the m/z bins entering and leaving the top-count ranking. It uses the same per-class PCC reference sets at thresholds 0.3, 0.4, 0.5 and 0.6. At each threshold, the mixed positive set is the union of class-positive bins; F1 compares selected bins with that set, and mSCF1 is the mean of the four mixed F1 scores. The [scoring implementation](../../../code/msi/scripts/evaluate_spatial_msipl_attributed_peaks.py) and [ranking-swap implementation](../../../code/msi/scripts/evaluate_spatial_attention_frozen_ranking_swap.py) define these operations.

## Claims and limits

| The trained attention model uses neighbour input. | Frozen input swap: shuffled/real reconstruction MSE is 1.36–3.38 across 16/16 sections; fixed-GMM labels also change (mean flip fraction 4.27% CAC, 8.48% GBM, unweighted over eight sections each). [Section summaries](../../../code/msi/results/diagnostics/spatial_attention_input_swap/). | Supported as input sensitivity. | That the input is beneficial, spatially specific, or robust to other training seeds. |
| Real neighbours consistently improve the frozen model's peak selection. | Same-checkpoint ranking swap: real mSCF1 is higher in 4/8 CAC and 1/8 GBM sections; shuffled is higher in 4/8 CAC and 7/8 GBM. Mean shuffled-minus-real mSCF1 is +0.0049 CAC and +0.0183 GBM. [Section summaries](../../../code/msi/results/diagnostics/spatial_attention_frozen_ranking_swap/) and [overview figure](../../../results/model-comparisons/attention_frozen_ranking_swap_overview.png). | Not supported by this diagnostic; CAC is mixed and GBM usually favours shuffled input. | That shuffling would improve a retrained model or that real context is harmful. The intervention can be out of distribution. |
| The changed selected bins account for the mSCF1 changes. | All 16 changed-peak audits report `valid`; local cross-check on 6 October confirmed their real/shuffled scores exactly equal the corresponding ranking-swap scores, and each audit's entering count equals its leaving count. For example, `240TopL` loses 10/11/9/3 reference-positive bins at the four thresholds when shuffled; `GBM12_2` gains 30/34/35/26. [Changed-bin CSVs and summaries](../../../code/msi/results/diagnostics/spatial_attention_changed_peaks/). | Supported as score arithmetic under the frozen reference rule. | Why IG moved those bins or whether changed ion images identify molecules. |
| Neighbour scale or a learned spatial mechanism solves the CAC–GBM difference. | The [48-configuration window campaign](../../../code/msi/results/experiments/spatial_msipl_window_pilot/) and attention interventions show different section-level patterns; the real-versus-shuffled attention ranking has mixed CAC outcomes. | Open. | A causal account of tissue boundaries, coverage, normalisation, encoder capacity, GMM fit or dataset biology. |
| The nonlocal shuffle resembles the real-trained model's centre–context inputs. | The [6 October distribution screen](../../../code/msi/results/diagnostics/spatial_attention_context_shift/) sampled 512 centres per outcome-known section. Shuffled cosine fell below the real 5th percentile for 81.1% of `160TopL` and 66.2% of `GBM22_2` samples; half-L1 exceeded the real 95th percentile for 92.0% and 70.9%. The exact earlier source-slot hashes matched. | Contradicted on these two input statistics; a substantial input-relationship shift is observed. | A formal full-model OOD test, a causal explanation of the IG ranking, or an independent section-level confirmation. |

## Provenance and next decision

The frozen ranking uses [evaluate_spatial_attention_frozen_ranking_swap.py](../../../code/msi/scripts/evaluate_spatial_attention_frozen_ranking_swap.py); the changed-bin audit uses [audit_spatial_attention_changed_peaks.py](../../../code/msi/scripts/audit_spatial_attention_changed_peaks.py). Representative raw files are [`GBM22_2` ranking summary](../../../code/msi/results/diagnostics/spatial_attention_frozen_ranking_swap/GBM22_2/summary.json), [`GBM22_2` changed-peak summary](../../../code/msi/results/diagnostics/spatial_attention_changed_peaks/GBM22_2/summary.json), and the [section-level derived table](../../../results/model-comparisons/attention_frozen_ranking_swap_sections.csv). The saved summaries include section, peak budget, checkpoint path/hash, sampled pixels and IG settings; they do not all embed an exact cluster Git revision, so the local repository revision must not be presented as verified cluster provenance. The raw audit output also retains a few pilot-era limitation strings referring to two sections; the 16-section aggregate above is recomputed from all present summaries.

The strongest defensible statement today is: **the attention model is sensitive to neighbour input, but these seed-1 interventions do not establish that real spatial context improves peak selection.** The two-section input screen makes the frozen nonlocal shuffle especially unsuitable as a fair effectiveness comparison. The separately trained real-versus-shuffled seed-1 mSCF1 differences are only +0.0044 on `160TopL` and −0.0058 on `GBM22_2`, both below the predeclared 0.02 practical signal; targeted repeats would quantify their stability, not rescue the frozen swap as a positive result. Separately complete the S3PL quality/runtime and full claim-to-raw-artifact audits. None of those open questions is resolved by the 16/16 file count alone.
