MS CLUSTER NODE ISSUE LOG
=========================

Purpose
-------
Keep a factual record of node-specific problems observed during this research.
An entry means that one of our jobs had a problem on the node. It does not prove
that the physical node is broken. In particular, a node may work for CPU jobs
while not exposing a usable NVIDIA GPU/CUDA runtime.

How to identify a failed job's node
-----------------------------------

Run on the cluster, replacing JOB_ID:

  sacct -j JOB_ID --format=JobID,JobName,State,Elapsed,NodeList,ExitCode

Add the allocated NodeList and exact symptom to this file. Do not add nodes that
only appeared as down in a general sinfo listing unless one of our jobs actually
failed there.
